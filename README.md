# search-o-SAURS

This repository contains a Boolean Information Retrieval system for the Cranfield Aeronautics Corpus, developed for an Information Retrieval programming assignment.

The implementation, usage instructions, project structure, and testing details are available in the [IR_P1 README](IR_P1/README.md).

The Assignment 2 ranked-retrieval work is in [IR_P2](IR_P2/README.md). Its current implementation and remaining submission requirements are documented there.
